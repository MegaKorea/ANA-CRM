# Product Context (ANA-CRM)

## Vì sao dự án tồn tại

- CRM phục vụ quản lý vận hành (lớp học/khách hàng/lịch học/…); UI thiên về form/table, nhập liệu và theo dõi trạng thái.

## Người dùng & nhu cầu

- Người dùng nội bộ: cần thao tác nhanh, ít lỗi, hiển thị dữ liệu rõ ràng, tìm kiếm/lọc/sắp xếp tốt.

## Mục tiêu trải nghiệm

- **Nhanh**: trang list/detail tải nhanh, tương tác mượt.
- **Nhất quán**: cùng pattern cho form validation, thông báo, confirm, error handling.
- **Giảm công lặp**: component shared tái sử dụng, service có chuẩn gọi API thống nhất.

## Ghi chú

- Sẽ cập nhật cụ thể theo module sau khi quét `app/`.
